# My First Responsive Frontend with Bootstrap 🚀

I'm excited to share my first frontend project built with **Bootstrap** — created to strengthen my understanding of responsive web design, CSS animations, interactive UI elements, and modern frontend development. 💻

## 🌐 Project Overview

Strict is a responsive frontend website designed with a focus on clean layouts, visual interactions, and responsive user experience.

This project allowed me to move beyond basic HTML & CSS and explore how **Bootstrap and CSS animations** can be combined to create a more engaging interface.

## ✨ Key Features at a Glance

✅ Responsive Bootstrap Navbar  
✅ Mobile & Tablet-Friendly Navigation  
✅ Animated Hero/Banner Section  
✅ CSS Keyframe Animation  
✅ Gradient-Based 3D Icon Effects  
✅ Interactive Photo Gallery  
✅ Smooth Image Overlay Animation  
✅ Animated Gallery Icons  
✅ Newsletter Subscription Form  

## 📱 Responsive Navigation

Built the navigation using **Bootstrap's responsive navbar component**.

The navbar automatically collapses into a mobile-friendly menu when the screen size becomes smaller, providing a better experience across:

- 💻 Desktop
- 📱 Smartphone
- 📲 Tablet

## 🎬 Animated Hero Section

Added a custom **CSS keyframe animation** to the banner section.

An animated arrow adds movement to the hero area and creates a more dynamic first impression when visitors land on the website.

## 🎨 Gradient 3D Icon Effect

Experimented with **CSS gradients** to create a dimensional, 3D-style appearance for the icons.

This helped me understand how gradients can be used beyond simple backgrounds to create more visually interesting UI elements.

## 🖼️ Interactive Photo Gallery

Created a photo gallery with animated image overlays.

When the user hovers over an image:

- The overlay smoothly moves from bottom to top.
- The associated icon appears with a coordinated animation.
- Both elements work together to create a smooth hover interaction.

This was one of the main parts of the project where I practiced combining **CSS transitions, positioning, and animation**.

## 📩 Newsletter Subscription

Added a newsletter subscription section at the end of the website with a dedicated form interface for visitors to subscribe.

## 🛠️ Technologies Used

- **HTML5** — Website structure
- **CSS3** — Styling, animations, gradients & hover effects
- **Bootstrap** — Responsive layout and navigation
- **JavaScript** — Interactive functionality
